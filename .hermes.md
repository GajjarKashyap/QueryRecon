# QueryRecon Hermes context

QueryRecon V2 is a local-first Vite, React, and TypeScript OSINT workspace. Key areas are `src/pages`, `src/components`, `src/core`, and `src/store`. The browser runs on port 5173; Hermes runs locally on port 8642. Important workflows are Query Builder, Research Mode, AI Court, Investigation Board, and the Hermes assistant.

## Bedrock

- Amazon Bedrock is routed through Hermes with provider `bedrock` and exact Bedrock model IDs.
- One Bedrock long-term key can authorize multiple models enabled for the same AWS account and region.
- Credentials belong only in the Hermes environment as `AWS_BEARER_TOKEN_BEDROCK`; never request, display, copy into source, or commit that value.
- QueryRecon's smart router sends short/simple prompts to the configured cheap model and research, coding, analysis, or multi-step work to the configured powerful model.
